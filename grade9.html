📐 Unit 1: Further on Sets (Interactive Quizzes)


🟢 1. [EASY] If set A = {1, 2, 3, 4} and set B = {3, 4, 5, 6}, what is A ∩ B?

🟡 2. [MEDIUM] Given set A with n(A) = 5 elements. How many proper subsets does set A have?

🔴 3. [HARD] In a class of 40 students, 25 play Football, 20 play Basketball, and 5 play neither game. How many students play BOTH Football and Basketball?

🔥 4. [HOT - Higher Order Thinking] Let A and B be non-empty sets. If A ⊆ B, which of the following statements MUST be true?
